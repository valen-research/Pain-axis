Code, data and results for the self-other tests added in v3 of "The Pain Axis" (Section 4.1.1 and Appendices E–G).
Each numbered folder contains the scripts, inputs and outputs needed to reproduce the results of one test.

The scripts in `1-embedding tests/` read the datasets and the 25-model results from the enclosing repository. Set `PAIN_AXIS_REPO` to point them at a different copy.
